# 🤖 AI Interview Coach

An AI-powered technical interview platform that simulates a real interview experience using **LLMs, Retrieval-Augmented Generation (RAG), semantic search, and automated answer evaluation**.

Candidates can select a role, topic, and difficulty level, complete a five-question technical interview, and receive a final performance report with scores, strengths, areas for improvement, recommended topics, and a hiring recommendation.

---

## 📌 Project Overview

Preparing for technical interviews often requires practicing questions repeatedly and receiving meaningful feedback.

The **AI Interview Coach** was built to provide a more realistic and personalized interview experience.

Instead of showing the candidate the score after every question, the application conducts the interview as a complete session:

```text
Candidate
    ↓
Select Role / Topic / Difficulty
    ↓
Start Interview
    ↓
AI-generated Technical Question
    ↓
Candidate Answer
    ↓
RAG + LLM Evaluation
    ↓
Next Question
    ↓
(5 Questions)
    ↓
Final Evaluation
    ↓
Interview Report
